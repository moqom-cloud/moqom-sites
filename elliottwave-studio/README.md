# elliottwave.studio

The company site for elliottwave.studio lab (legal entity: Elliott Wave LLC). Static [Astro](https://astro.build) site, no client-side JavaScript.

## Develop

Requires Node 22.12+ and pnpm 10+.

```sh
pnpm install
pnpm dev        # http://localhost:4321
pnpm build      # static output in dist/
pnpm preview    # serve dist/ locally
```

`pnpm-workspace.yaml` allows esbuild's install script (`allowBuilds`), which pnpm 10+ blocks by default.

## Layout

```
src/
  components/Wave.astro    Generative Elliott-wave SVG (build time, respects prefers-reduced-motion)
  components/Metrics.astro MOQOM benchmark block; always renders the lab-measurement label
  data/moqom.ts            Benchmark numbers, footnote, platform status, links. Edit numbers here only
  data/six10nine.ts        six10nine copy (outcome level only), licence, release status
  data/press.ts            /press copy: boilerplate, fact sheet, headline numbers, assets, launch post URLs
  layouts/Base.astro       <head> (SEO, Open Graph, Twitter, JSON-LD), header, footer
  pages/                   /, /work, /approach, /about, /contact, /press, /legal, 404
  styles/global.css        Brand tokens
public/
  og.png / og.svg          Social card (og.png is rendered from og.svg; regenerate with `sips -s format png og.svg --out og.png`)
  robots.txt, favicon.svg, .well-known/security.txt
  images/elliott.jpg       Founder portrait (not present yet; /about shows an "E" monogram until it exists)
```

The sitemap (`sitemap-index.xml`) is generated by `@astrojs/sitemap` from `site` in `astro.config.mjs`.

## Content rules

- Don't describe how MOQOM's or six10nine's technology works. State outcomes only.
- Brand display name is "elliottwave.studio lab"; the legal entity in copyright and legal notices is "Elliott Wave LLC".
- Every benchmark must carry "* Built to scale: a Rust media plane and a Go control plane, each scaling out horizontally. Measured in lab, tested to 6,000 viewers on one 4-vCPU relay with zero loss; pending further load testing." (`BENCH_LABEL`). `Metrics.astro` handles this; keep it if you add numbers elsewhere.
- No partnership, customer or testimonial claims beyond what `/work` says ("No partnership is signed yet").
- Cyan (`--moqom`) is used only inside `.moqom` sections that showcase MOQOM. The studio accent is amber.
- Footer copy is fixed: "© 2026 Elliott Wave LLC. elliottwave.studio lab. All rights reserved. MOQOM and six10nine are trademarks of Elliott Wave LLC. Patents pending." plus the IP ownership line.

## Deploy (Cloudflare Pages, later)

Not deployed yet. When ready:

1. Create a Pages project connected to the repository (or upload `dist/` with `wrangler pages deploy dist`).
2. Settings: framework preset **Astro**, build command `pnpm build`, output directory `dist`, root directory `sites/elliottwave-studio` if this lives in a monorepo.
3. Set `NODE_VERSION=22` (or newer) in the environment variables.
4. Add the custom domain `elliottwave.studio`. Cloudflare Pages serves `dist/404.html` for unknown routes automatically.
5. Optional: add a `public/_headers` file for security headers (CSP, HSTS) and long cache lifetimes on `/_astro/*`.
