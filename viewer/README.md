# viewer.elliottwave.studio

Docs site for 3D Viewer. Astro, static, same conventions as `sites/elliottwave-dev` (shared CSP/SRI check from `../_shared/security/csp.mjs`, sitemap, dark theme).

```sh
pnpm install
pnpm build     # dist/, fails on any CSP/SRI problem
pnpm preview
```

## Where things come from

- `src/vendor/` is copied from the viewer repo by its `scripts/sync-docs.mjs`. Don't edit it here: change the viewer repo, run `pnpm build` there, then `pnpm sync:docs <path to this folder>`.
- `src/data/site.ts` holds the product name, URLs and emails. Renaming the product starts there.
- `src/assets/demo/knot.glb` is generated by the viewer repo's `scripts/make-sample-glb.mjs`.

## CSP notes

- `<model-viewer>` renders one `<style>` in its shadow root; `astro.config.mjs` allows it by the hash in `src/vendor/release.json` (`styleHashes`).
- Pages with the snippet generator or URL checker call `allowVisitorModels(Astro)` (`src/lib/csp.ts`) to allow `https:` for fetch and images and `blob:` workers. It must be called in the page, not a component.
- No syntax highlighting (it would add inline `style` attributes) and `assetsInlineLimit: 0` (no `data:` URIs).
