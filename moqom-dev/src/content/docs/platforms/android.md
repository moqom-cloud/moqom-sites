:::note[Status]
**In progress. Coming Q4 2026.**
:::

The Android SDK will bring MOQOM rooms to Android phones and tablets, using the same room, role
and token model as the [Swift SDK](/guides/ios-macos/). Tokens are minted by your backend exactly
as today, so no backend changes are needed to add Android clients.

Until it ships, Android is not a supported client. See [Platform status](/platforms/status/).
