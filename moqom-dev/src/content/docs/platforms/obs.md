:::note[Status]
**Scoped, work ongoing.**
:::

The OBS plugin will let creators broadcast from OBS Studio straight into a MOQOM room as a
publisher, with viewers watching on any MOQOM client.

Your backend will mint a broadcaster token for the plugin the same way it does for any other
publisher. See [Platform status](/platforms/status/).
