:::note[Status]
**In progress. Coming Q4 2026.**
:::

The desktop SDK will cover Windows and Linux applications, and cross-platform desktop apps on
macOS. Native macOS apps can use [`MoqomKit`](/guides/ios-macos/) today.

It will use the same room, role and token model as every other MOQOM client, so no backend changes
are needed. See [Platform status](/platforms/status/).
